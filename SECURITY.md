# Política de seguridad

## Cómo informar de una vulnerabilidad

Escribe a security@wirehaus.dev con el asunto `Wirehaus: vulnerabilidad`. No abras un issue público ni publiques los detalles antes de que haya una corrección.

Incluye la versión afectada, el sistema operativo, los pasos para reproducirlo y el impacto que crees que tiene.

## Qué puedes esperar

- Acuse de recibo en un plazo de siete días.
- Una valoración del problema y, si se confirma, un plan de corrección.
- Reconocimiento en el registro de cambios si lo deseas.

## Versiones con soporte

Solo la última versión menor publicada recibe correcciones de seguridad (hoy, la 0.2).

## Alcance

Entra en el alcance el agente, el protocolo y el visor web. No entran los fallos de software de terceros que Wirehaus usa como dependencia: informa de ellos a sus responsables.

## English

Report vulnerabilities to security@wirehaus.dev with the subject `Wirehaus: vulnerability`. Do not open a public issue or publish details before a fix exists. Include the affected version, the operating system, the steps to reproduce and the impact you expect. You will get an acknowledgement within seven days. Only the latest published minor version (currently 0.2) receives security fixes. The agent, the protocol and the web viewer are in scope; flaws in third-party dependencies should be reported to their maintainers.
